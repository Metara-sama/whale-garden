# 趋势实验室 · trend-lab

输入任意词，看它在 8 个平台的搜索词频折线。时间自己拖，平台可以分开看也可以合起来看。纯静态、零依赖、零请求，整站 75KB。

线上：<https://Metara-sama.github.io/whale-garden/projects/trend-lab/>

## 用法

1. 输入框里打字，回车（或点 ＋）加一个词，最多同时看 3 个；逗号 / 空格可以一次加多个
2. 点平台方块挑平台，`全选 / 全不选` 一键切；默认 5 个
3. 拖时间滑块，或用 7 / 30 / 90 / 全部
4. 视图：`合计`（选中平台相加）· `分平台`（同一坐标系里一词一色一平台）· `分面`（一平台一块面板）
5. 其他：日 / 周粒度、归一化（每条线均值=100，只比形状）、图例点一下隐藏、悬停出十字线与数值、存图、CSV

## 平台

百度 · 微信 · 抖音 · 微博 · 小红书 · B站 · 知乎 · 头条

每个平台有自己的量级、周内节奏（小红书/B站周末高，微信/知乎工作日高），以及事件滞后：
微博最先起，抖音/小红书跟上，百度慢半拍，知乎最晚。

## 数据是怎么来的

**没有抓任何东西，也不预设任何词。** 你输入的词名就是种子：

- `hash(词)` 决定这个词本身多热、季节相位、慢趋势、以及 1–3 次突发窗口
- `hash(词 + 平台)` 决定各平台自己的噪声
- 同一个词，任何时候、任何设备打开，曲线完全一样（不用 `Math.random`）

所以它是**演示数据**：形状像真的，数值不是真实搜索量。要真数据就得自己接接口，
静态站直连会被 CORS 拦，这块在上一版试过（百度自带 `error` 字段的坑、公共代理全挂），
后来按需求把抓取整个去掉了。

## 目录

```
index.html        页面骨架
css/style.css     极简浅色样式
js/model.js       8 平台 × 确定性曲线生成（哈希种子 + 周内周期 + 事件滞后）
js/chart.js       canvas 折线引擎（单调三次插值、多面板、动画、十字线、tooltip）
js/app.js         状态、聚合、统计、交互、导出
```

改平台就改 `js/model.js` 顶上的 `PLATS`（`w` 权重 / `lag` 滞后 / `wkDay`·`wkEnd` 周内节奏 / `color`），
页面上的平台方块、图例、颜色、分面顺序都会跟着变。

## 踩过的坑

| 坑 | 说明 |
|---|---|
| 脚本缓存 | 改完 JS 记得把 `index.html` 里的 `?v=` 往上加一位，否则浏览器拿旧的。 |
| 双端滑块 | 两个 `input[type=range]` 叠在一起时，给 input 设 `pointer-events:none`、只给 `::-webkit-slider-thumb` 设 `auto`，两个把手才能各自拖。 |
| 多线看不清 | 线数 > 3 就自动关掉面积填充，否则渐变叠成一坨。 |
| 分面高度 | 面板数是不定的，图表高度按 `平台数 × 每面板高` 算，别写死。 |
