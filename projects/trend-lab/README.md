# 趋势实验室 · trend-lab

百度 / B站 / 微博 三个平台的热词强度，按你自己拖出来的时间段画折线。极简浅色，纯静态，无框架、无 CDN、无依赖。

线上：<https://Metara-sama.github.io/whale-garden/projects/trend-lab/>

## 它能干什么

- **三种视图**
  - `合计`：选中平台的词频相加，一个词一条线
  - `平台对比`：一个坐标系里画「词 × 平台」，平台上色、词用虚实线区分
  - `分面`：一个平台一块面板，上下堆叠，共享时间轴
- **时间自己调**：双端滑块拖起止日期，或 7 / 30 / 90 / 全部 一键切；日粒度或 7 天均值
- **归一化**：每条线以自身区间均值 = 100，专门用来看「形状」而不是「量级」
- **悬停十字线 + 跨面板 tooltip**、图例点击隐藏、KPI（区间合计 / 峰值日 / 后半段 vs 前半段）、平台份额条
- **存图 / 导 CSV**
- **今日实时快照**：真去抓三家的公开热搜榜，统计「你关心的词今天在榜单里命中几条」

## 目录

```
index.html          页面骨架
css/style.css       极简浅色样式（手写，无框架）
js/data.js          内置数据集（140 天 × 18 词 × 3 平台，自动生成，别手改）
js/chart.js         canvas 折线引擎（单调三次插值、多面板、动画、十字线）
js/live.js          抓取通道 + 词频统计
js/app.js           状态、聚合、统计、交互
tools/gen_data.py   重新生成 data.js
tools/bridge.py     本地抓取桥（绕开 CORS）
```

## 数据是怎么来的（老实说）

- **历史曲线是示例数据**：`tools/gen_data.py` 按公开热搜的形态构造，带周内周期、事件脉冲、平台错峰（微博先爆 → B站滞后 1–2 天 → 百度滞后 1 天），用来演示「同一件事三家不一样」这件事，**不是爬下来的真实历史**。改词表/量级就改那个脚本，然后 `python3 tools/gen_data.py`。
- **今日快照是真实请求**：页面会依次尝试
  1. **本地桥** `http://127.0.0.1:8899` —— 最稳，推荐
  2. 直连官方接口（大多会被 CORS 拦）
  3. 公共 CORS 代理（可用性看运气，可在页面里自己换）
- **词频口径**：目标词在榜单标题里的命中条数。这是静态页能诚实拿到的量，跟平台真实搜索量不是一回事。

## 本地桥怎么跑

```sh
python3 tools/bridge.py                # 只本机可访问
python3 tools/bridge.py --host 0.0.0.0 # 局域网也能访问（手机开页面、电脑跑桥）
```

跑起来之后，页面「今日实时快照 → 抓不到？」里点一下「测一下」，显示 ✓ 就能抓了。
桥只做三件事：收请求、拉一次官方榜单、原样吐 JSON 并加 CORS 头。只读、不落盘、30 行级代码，可以自己审。

## 踩过的坑

| 坑 | 说明 |
|---|---|
| 百度接口带 `error` 字段 | 正常响应里也有 `error: {}`，把 `if (json.error)` 当故障会把百度全判成失败。只认「非空字符串」。 |
| 百度榜单是嵌套的 | `data.cards[0].content[0].content[]` 才是词，少一层就得到一堆 undefined。 |
| 公共代理几乎全死 | allorigins / codetabs 超时，corsproxy 401，cors.lol 429 —— 所以才有本地桥。 |
| 脚本缓存 | 改完 JS 记得把 `index.html` 里的 `?v=` 往上加一位，否则浏览器拿旧的。 |
| CORS 豁免 | 公网页面访问 `http://127.0.0.1` 在 Chrome 里是允许的（localhost 属可信源），但桥要带 `Access-Control-Allow-Private-Network: true`。 |
