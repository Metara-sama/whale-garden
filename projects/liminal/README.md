# 阈限 · Liminal

梦核 / 池核风格的第一人称阈限空间。三个场景循环：**池核 → 黄色后室 → 黄昏草甸 → 回池核**。
没有任务、没有分数、几乎没有文字。

线上：<https://Metara-sama.github.io/whale-garden/projects/liminal/>

## 怎么玩

- **左下角摇杆**：推着走。**空白处拖动**：转头。
- 桌面也能玩：`WASD`/方向键 + 鼠标拖动，`1` 键强制切场景。
- 走到场景尽头的光里（池核侧厅尽头的白门 / 后室走到雾变白 / 草地上的白门）就会换场景。
- 右上角是声音开关，左下角（摇杆下方）是站点统一的全屏按钮。

## 池核是一串连起来的房间

`A 泳池大厅 → B 连接走廊 → C 浅水房 → E 侧门洞 → D 侧厅（尽头是白门）`

- **池深 1.15m**：眼睛始终高于水面，走进去只是"站在齐胸的水里"，绝不会被困在池底。
- **浅水房尽头两扇发光门洞是真能走进去的**：穿过门洞会直接白闪进后室。手机摇杆推着走，速度按地面/涉水区分（陆上 3.1、浅水 1.45、池中 1.8 m/s）。
- **浅水房**地面下沉 0.35m，水漫过地面，走起来会慢。
- A / C 两侧墙上有成排的竖向灯带；池中央浮着红色浮圈；C 尽头墙上有两扇发光门洞当视觉纵深。
- 房间之间是**重叠的并集**（并在 CPU 侧做"房间夹取"），所以能穿过门洞、也不会穿墙。

## 它是怎么画出来的

**没有一个外部资源文件**，不到 90KB，6 个文件：

| 文件 | 作用 |
|---|---|
| `index.html` | 起幕（呼吸的点 + 真实进度条）、摇杆、声音开关、全屏组件 |
| `js/textures.js` | Canvas2D 现画 4 张材质：池核瓷砖 / 后室墙纸 / 地毯 / 胶片颗粒 |
| `js/shaders.js` | 全部 GLSL：三套 SDF 场景 + 光照 + 体积光 + 水面 + 后期 |
| `js/audio.js` | WebAudio 现场合成的三套环境音（水声 / 荧光灯嗡鸣 / 风声虫鸣） |
| `js/engine.js` | WebGL2 装配、主循环、摇杆与视角、房间夹取、转场、自适应分辨率 |

### 渲染链

```
scene (raymarching, 单 draw call)
  → accum （时域累积 ping-pong，静止时最多叠 13 帧）
  → bright + blur （1/4 分辨率，提取 HDR 亮部）
  → post （ACES 色调映射 + 色差 + 暗角 + 胶片颗粒）→ 屏幕
```

- **建模方式**：全部 SDF（sphere tracing），米为单位。池核 = 5 个房间盒求并集、地板再挖掉池洞与浅水洞；后室 = 9m 网格上 3.6m 见方的大隔墙 + 嵌顶日光灯管（按参考图还原：竖条纹墙纸、米黄地毯、深色踢脚线、白色吊顶被灯烘亮）；草地 = 高度场 + 一棵树 + 一扇发光白门。
- **水面**：主射线先算池底（深度吸收 + 焦散），再单独求水面交点做一次低步数反射 march，按菲涅耳混合，最后压一层墨绿水色（参考现实池核的照片，水是深绿的而不是蓝的）。
- **体积光**：沿射线累积 `glowAt(p) * ds * exp(-tau) * 雾密度`。
- **静止即凝固**：停下就不再推进时间、开始叠帧去噪，收敛完（13 帧）干脆停止渲染——省电，而且"世界停了、画面慢慢显影"本身就是这个作品的表达。
- **自适应分辨率**：帧时间中位数 > 37ms 降内部分辨率（0.36~0.92 倍），< 21.5ms 升回去。

## 两个必须记住的坑

1. **房间盒的下界必须低于池底**。池子是从地板里挖出来的；如果房间盒底边正好在 y=0，池内区域会被"假地面"顶飞，射线直接未命中，整屏退化成雾色（看着像过曝白屏）。
2. **池口不是实体面**。池子的空气距离只能用池壁 + 池底算，不能把池当成一个有顶的盒子，否则水面附近距离趋零，sphere tracing 会在那儿蹭到步数耗尽。

## 调参入口

`js/engine.js` 顶部 `SCENES`：每个场景的 `steps / fov / exposure / pos / yaw / pitch`；`ROOMS` 是池核的房间盒（改房间要同时改 `js/shaders.js` 里的 `sdRoomX`）。
`js/shaders.js`：`shadePool / shadeRooms / shadeMeadow` 各自的光照与反照率；`fogColorAt / fogDensity` 控雾；`waterLayer` 控水面。

**改了 js 记得把 `index.html` 里的 `?v=N` 一起 +1**，否则浏览器会拿旧缓存。

## 调试

URL 加 `?diag` 会：
- 顶部显示一条红色诊断（WebGL2 / floatRT / 缓冲区尺寸）；
- 挂载 `window.__LIM`：`info()` 读相机位置与状态、`scan(cols, rows)` 把累积缓冲的 HDR 亮度网格读回来、`go(i)` 切场景、`walk(n, fwd, right)` 用固定步长跑物理（用来验证走动/落地/触发，绕开后台 rAF 节流）、`probe()` 读几个点的浮点像素。

这是在没有屏幕的环境里（设备锁屏、截图全黑）验证画面的唯一可靠手段。

## 已知限制

- 需要 **WebGL2**。没有的话起幕会直接显示原因，不会白屏。
- `EXT_color_buffer_float` 缺失时退回 RGBA8 累积（会有一点色带，功能不受影响）。
- 浮圈只是视觉道具，玩家可以穿过去（没有做圆形碰撞）。
- 后室柱阵按"格心推开"近似碰撞，贴柱子转圈时会有轻微推挤感。
