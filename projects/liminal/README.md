# 阈限 · Liminal

梦核 / 池核风格的第一人称阈限空间。三个场景循环：**瓷砖泳池 → 黄色后室 → 黄昏草甸 → 回泳池**。
没有任务、没有分数、几乎没有文字。

线上：<https://Metara-sama.github.io/whale-garden/projects/liminal/>

## 怎么玩

- **手机**：按住屏幕就往前走，手指左右拖动改变朝向，松手就停下。
- **桌面**：`WASD` / 方向键走，鼠标拖动看，`1` 键强制切场景。
- 走到场景尽头的光里（泳池尽头的白门 / 后室走到雾变白 / 草地上的白门）就会换场景。
- 右上角是声音开关，左下角是站点统一的全屏按钮。

## 它是怎么画出来的

**没有一个外部资源文件**，91KB，5 个文件：

| 文件 | 作用 |
|---|---|
| `index.html` | 起幕（呼吸的点 + 真实进度条）、声音开关、全屏组件 |
| `js/textures.js` | Canvas2D 现画 4 张材质：池核瓷砖 / 后室墙纸 / 地毯 / 胶片颗粒 |
| `js/shaders.js` | 全部 GLSL：三套 SDF 场景 + 光照 + 体积光 + 水面 + 后期 |
| `js/audio.js` | WebAudio 现场合成的三套环境音（水声 / 荧光灯嗡鸣 / 风声虫鸣） |
| `js/engine.js` | WebGL2 装配、主循环、输入、碰撞、转场、自适应分辨率 |

### 渲染链

```
scene (raymarching, 单 draw call)
  → accum （时域累积 ping-pong，静止时最多叠 13 帧）
  → bright + blur （1/4 分辨率，提取 HDR 亮部）
  → post （ACES 色调映射 + 色差 + 暗角 + 胶片颗粒）→ 屏幕
```

- **建模方式**：全部 SDF（sphere tracing），米为单位。泳池 = 房间内部距离场挖出池子（池口不能当实体面，否则步进会在水面附近原地蹭死在 0.01）；后室 = 6.4m 周期的柱阵 + 天花板灯板；草地 = 高度场 + 一棵树 + 一扇发光白门。
- **水面**：主射线穿过水面先算池底（含深度吸收 + 焦散），然后单独求水面交点，做一次低步数的反射 march，按菲涅耳混合；水下相机时反射比拉高（近似全内反射）。
- **体积光**：沿射线累积 `glowAt(p) * ds * exp(-tau) * 雾密度`，让灯、门、天窗自然带出光晕。
- **静止即凝固**：不再推进时间、开始叠帧去噪，收敛完（13 帧）干脆停止渲染——省电，而且"世界停了、画面慢慢显影"本身就是这个作品的表达。
- **自适应分辨率**：帧时间中位数 > 37ms 就降内部分辨率（0.36~0.92 倍），< 21.5ms 就升回去。
- **转场**：0.5s 白闪过曝 → 换场景 → 1.2s 白雾退去，配一层噪声上扬；白闪按真实时间衰减，低帧率也不会卡在白屏。

## 调参入口

`js/engine.js` 顶部 `SCENES`：每个场景的 `steps / fov / exposure / pos / yaw / pitch`。
`js/shaders.js`：`shadePool / shadeRooms / shadeMeadow` 三个函数各自的光照与反照率；`fogColorAt / fogDensity` 控雾；`waterLayer` 控水面。

## 调试

URL 加 `?diag` 会：
- 顶部显示一条红色诊断（WebGL2 / floatRT / 缓冲区尺寸 / 计算样式）；
- 挂载 `window.__LIM`：`info()` 读状态、`scan(cols, rows)` 把累积缓冲的 HDR 亮度网格读回来、`go(i)` 直接切场景、`probe()` 读几个点的浮点像素值。

这是在没有屏幕的环境里验证画面的唯一可靠手段（截图会被锁屏、缓存、合成层干扰）。

## 已知限制

- 需要 **WebGL2**。没有的话起幕会直接显示原因，不会白屏。
- `EXT_color_buffer_float` 缺失时自动退回 RGBA8 累积（会有一点色带，功能不受影响）。
- 后室是周期重复的空间，柱子碰撞按"格心推开"近似，贴柱子转圈时会有轻微推挤感。
- 水面反射是单次低步数 march，掠射角极远处会有少量高频碎光——静止累积后会变成柔和的波光。
