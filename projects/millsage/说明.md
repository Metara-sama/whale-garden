# millsage 剧情演示 · 使用说明

## 文件
- `story_silent.html`　无声版（立绘已内嵌，单文件即可分享）
- `story_voice.html`　有声版（逐句播放游戏原声语音，需联网；立绘同样内嵌）
- `立绘/`　裁剪后的白底立绘（hotaru/natsume/nagi/mahoro/houka/kanade），仅作备份
- `fetch_voice.py`　可选：把语音下载到本地做离线版

## 收录
共 131 话 / 5563 条对话，源站 bdon.moe（数据来自游戏脚本）。

- 主线剧情：25 话（3377 条）
- 活动剧情：9 话（776 条）
- 羁绊剧情：30 话（1254 条）
- 演出结束对话：60 话（120 条）
- 主页成员对话：7 话（36 条）

## 流程
开局动画（白+彩虹，约 2.5s，可点击跳过）→「选择章节」页 → 剧情播放

## 操作
- 「选择章节」页：按分类列出全部章节，点一条即开始
- 播放中左上角「章节 ▾」可随时回到章节页（Esc 同效）
- 轻触画面 / → / 空格：下一句；←：上一句
- 「▶ 自动」：连续播放（有声版等语音播完再切下一句）
- 「1.0×」：切换语速；底部细线：拖动跳转
- 有声版选完章节就直接出声（那次点击即手势），无额外提示；若被浏览器拦下，点一下画面即静默重试

## 性能
动画只使用 transform + opacity（GPU 合成），不使用 blur 滤镜与 letter-spacing 补间，
立绘不做持续位移，避免 mix-blend-mode 每帧重算。

## 有声版离线化（可选）
1. `python3 fetch_voice.py main event friendship`（下载语音到 `音频/`）
2. 编辑 `story_voice.html`，把 `const PREFIX = "https://assets.bdon.moe/zh-Hans/Cri/Sound/";`
   改成 `const PREFIX = "音频/";` 即可。
